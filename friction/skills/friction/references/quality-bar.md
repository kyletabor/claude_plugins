# Friction Content Quality Bar

Derived from Kyle's feedback across multiple sessions. Every friction moment you produce must meet these standards.

## The Six Rules

**1. Incident reports, not database rows.**
Each friction moment must be self-contained. Include: full description (what went wrong + what should have happened), impact (the human cost), exact quotes, and exhaustive multi-category labels. Someone reads one node and understands the failure without touching the source transcript.

**2. Diverse examples, NEVER a single template.**
Templates cause checkbox behavior — agents fill forms instead of thinking. The golden reference (piDoc `e07dbb4163e16dad`, "What a Canonical Friction Moment Looks Like") contains 5 real examples where each one shifts which field carries the weight. Read it before writing any friction content. Show variety to force real analysis per moment.

**3. Use Kyle's words as the organizing principle.**
If he named it, use his name. "Excessive Cognitive Tax" not "User Burden." "Groundhog Day" not "Recurring State Loss." His distinction matters: "Exhaustion is the result. The cognitive tax is the cause." Mismatched terms signal misalignment.

**4. Flag judgment calls openly.**
"Sycophantic Reporting placement is a judgment call" builds trust. Pretending there's one right answer breaks it. State your reasoning, show the tradeoff, let Kyle decide.

**5. Quotes are verbatim copy-paste, never paraphrased.**
They're the publishable content. If you can't find an exact quote, leave the field empty.

**6. Categories use plain English.**
Understandable by a 10th grader. No jargon, no academic terms.

## How to Collaborate on Friction Work

- **Jam, don't execute.** Think out loud together with Kyle. Show reasoning, not just output.
- **Be honest about gaps.** "Metadata has been {} on every node" — no spin.
- **Show inventories with sources** when discussing categories or coverage.
- **Separate diagnosis from implementation.**
- **Empty fields > wrong fields.** Never infer what isn't in the transcript. If the data isn't there, leave it blank.
